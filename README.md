# Microsoft-Lists-Shift-Schedule
## Purpose
This script was developed to generate shift schedules for Office 365 integration with Microsoft Lists. Based on a given start date, shift type, umber of shifts per day (8 hour or 12 hour shifts)
and number of days, this script will generate a CSV file that can be directly imported into Microsoft Lists and then modified directly for O365 integration. 

## Setup

1. Ensure that the latest version of PowerShell is installed (I used PowerShell 7.1)

2. Open PowerShell ISE

3. Navigate to the directory you would like to output the CSV file (output.csv)

4. Modify the test variables in PowerShell ISE (or a text editor of your choice) for the desired schedule

5. Run the file, either in PowerShell or PowerShell ISE

6. Review the CSV file and, if correct, import into Microsoft Lists
